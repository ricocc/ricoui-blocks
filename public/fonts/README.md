# Website fonts

- `paper-mono-variable.woff2`: Paper Mono v1.000, normal, variable weights 100–800.
  Source: https://paper.design/mono
  Repository: https://github.com/paper-design/paper-mono

The unmodified WOFF2 variable font is served locally under SIL Open Font License
1.1; see `OFL.txt` for the original copyright notice and license.

Paper Mono is used for website headings, body copy, navigation, buttons, Docs,
code blocks, and auxiliary labels, with system monospace fallbacks. Canvas and
SVG artwork retain their own fonts. The font uses `font-display: swap` and a
single preload. It is website-only and is not distributed by the registry.
